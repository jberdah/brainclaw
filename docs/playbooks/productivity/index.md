# Productivity Playbook (End-users & Solo Devs)

Welcome to the Productivity Playbook. This guide is for developers and creators who want to use Brainclaw to maximize their output and keep their local AI coding agents organized.

Whether you are a solo developer managing a complex architecture or a non-technical creator instructing agents to build apps from scratch, Brainclaw acts as the persistent memory and organization layer.

## User Profiles

### Non-Tech Creators
You rely heavily on AI to write code for you. You don't need to learn command-line deeply.
**Key Value:** Zero-config setup. You tell the agent what to do, and the agent uses Brainclaw to remember context so you don't have to keep repeating yourself when you start a new session.
- **Workflow:** Just prompt your agent to setup Brainclaw: "Install and initialize brainclaw in this project so you can remember instructions."

### Solo Developers
You code alongside your agent.
**Key Value:** Persistent project constraints and memory. You can write your architecture decisions once, and the agent will respect them across all future edits.
- [Concepts: Memory](../../concepts/memory.md)
- [Concepts: Workspace Bootstrapping](../../concepts/workspace-bootstrapping.md)

### Power-Users
You orchestrate multiple agents.
**Key Value:** You can have an architect agent design the plan, and an execution agent code it up. Brainclaw acts as the handover point.
- [Concepts: Runtime Notes](../../concepts/runtime-notes.md)
