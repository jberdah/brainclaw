# Integration Playbook (AI Builders)

Welcome to the Integration Playbook. This guide is built to help product owners, developers of autonomous agents, and enterprise IT teams leverage Brainclaw as an enabling infrastructure.

Rather than building your own local memory and coordination states, you can adopt Brainclaw via its standardized Model Context Protocol (MCP) server.

## Integration Profiles

### Agent Integrators / Creators
You are building an AI app, a new coding agent, or a CLI wrapper.
**Key Value:** Save engineering time. Rely on Brainclaw's MCP to provide read & write access to project plans, constraints, and runtime memory natively out-of-the-box.
- [Integration Model](../../integrations/overview.md)
- [MCP Runtime Path](../../integrations/mcp.md)

### Enterprise AI Governance
You manage organizational compliance across many AI agents on developer desktops.
**Key Value:** All actions are auditable, verifiable, and transparent in Git. 
- [Security Model](../../security.md)
